# 🌍 Climate Intelligence Hub

AI-powered Climate Change Predictor with Hinglish Chatbot Support

## Features

- 🌡️ Temperature prediction (1850-2050)
- 🏙️ City-specific climate data (Lucknow, Delhi, Mumbai, etc.)
- 💬 Hinglish/Hindi/English chatbot
- 📊 Interactive charts and visualizations
- 🤖 CNN-LSTM hybrid ML model
- 🎨 Modern, responsive UI
